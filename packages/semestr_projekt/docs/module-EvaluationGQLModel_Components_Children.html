(static, constant) Children

Obalová komponenta pro předávání `item` do všech potomků. Využívá `ChildWrapper` ze shared knihovny, který automaticky clonuje všechny children elementy a předá jim prop `item`. Užitečné, pokud chceme jeden společný `item` injektovat do více komponent bez ručního předávání prop na každé místo.
Source:
  • Components/Children.jsx, line 32
Example
<Children item={evaluationItem}>
  <SomeComponent />
  <AnotherComponent />
</Children>
// Oba komponenty dostanou prop: item={evaluationItem}
